# 00 — Inbox

พื้นที่รับบันทึกใหม่ที่ยังไม่ต้องตัดสินใจว่าจะอยู่หมวดใด

## ใช้อย่างไร

1. สร้างไฟล์ชื่อ `YYYY-MM-DD-ชื่อเรื่อง.md`
2. เขียนสิ่งที่ต้องการเก็บให้เร็วที่สุด
3. ใส่แท็กที่นึกออก
4. เมื่อมีเวลา ค่อยย้ายไฟล์ไป `01-daily`, `02-notes`, `03-ideas`, `04-projects` หรือ `05-resources`

พยายามตรวจกล่องนี้อย่างน้อยเดือนละครั้ง ไม่จำเป็นต้องจัดหมวดทุกเรื่องทันที
