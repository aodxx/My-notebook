# ตัวอย่างบันทึกประจำวัน — 2026-08-23

> ไฟล์นี้เป็นข้อมูลตัวอย่าง ไม่ใช่เหตุการณ์จริงทั้งหมด

## วันนี้เกิดอะไรขึ้น

- เริ่มจัด GitHub Repository ให้เป็นสมุดบันทึกส่วนตัว
- แบ่งพื้นที่สำหรับ Inbox, Daily, Notes, Ideas, Projects และ Resources
- ทดลองใช้ Markdown สำหรับหัวข้อ รายการงาน ตาราง และลิงก์เชื่อมระหว่างบันทึก

## สิ่งที่ทำเสร็จ

- [x] สร้างโครงสร้างสมุดบันทึก
- [x] เตรียมแม่แบบภาษาไทย
- [x] เพิ่มตัวอย่างข้อมูล
- [ ] เปลี่ยน Repository เป็น Private ก่อนบันทึกข้อมูลส่วนตัว

## สิ่งที่เรียนรู้หรือคิดได้

การจดให้ทันสำคัญกว่าการเลือกหมวดให้ถูกทันที จึงควรเริ่มที่ Inbox แล้วค่อยจัดระเบียบภายหลัง

## ปัญหาหรือเรื่องที่ติดอยู่

ยังต้องทดลองว่าใช้ GitHub ผ่านมือถือแบบใดสะดวกที่สุด ระหว่างแก้ไฟล์ Markdown โดยตรงกับการจดผ่าน Issues

## สิ่งสำคัญสำหรับวันถัดไป

- [ ] สร้างบันทึกจริงชิ้นแรก
- [ ] ทดลองค้นหาด้วยคำว่า `google-apps-script`
- [ ] ตรวจ Inbox และย้ายเรื่องที่ศึกษาเสร็จแล้ว
