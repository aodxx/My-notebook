# 04 — Projects

พื้นที่ติดตามโปรเจกต์ที่กำลังทำหรืออยากทำ

แนะนำให้สร้างหนึ่งโฟลเดอร์ต่อหนึ่งโปรเจกต์:

```text
04-projects/
└── ชื่อโปรเจกต์/
    ├── README.md
    ├── decisions.md
    └── notes/
```

ใช้ [แม่แบบโปรเจกต์](../templates/project.md) เป็นไฟล์ `README.md` ของโปรเจกต์ เพื่อให้เห็นเป้าหมาย สถานะ และงานถัดไปในหน้าเดียว
