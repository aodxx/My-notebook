# ตัวอย่าง — AI ช่วยจัดระเบียบสมุดบันทึก

> ไฟล์นี้เป็นข้อมูลตัวอย่างสำหรับดูวิธีเปลี่ยนไอเดียให้เป็นการทดลองที่ทำได้จริง

## ปัญหาหรือโอกาส

เมื่อจดข้อมูลจำนวนมากไว้ใน Inbox อาจไม่มีเวลาย้ายไฟล์ ตั้งชื่อ เพิ่มแท็ก และเชื่อมโยงกับบันทึกเดิม

## ไอเดีย

สร้างผู้ช่วย AI ที่อ่านรายการจดด่วนจาก GitHub Issues แล้วเสนอ:

- ชื่อไฟล์ที่เหมาะสม
- หมวดปลายทาง
- สรุปสั้น ๆ
- แท็ก
- ลิงก์ไปยังบันทึกที่เกี่ยวข้อง

AI ควรสร้าง Pull Request ให้ตรวจสอบก่อน ไม่ควรย้ายหรือแก้บันทึกจริงโดยอัตโนมัติทันที

## ประโยชน์และผู้ใช้

- มีประโยชน์กับใคร: เจ้าของสมุดบันทึกที่จดข้อมูลบ่อย
- ช่วยเรื่องอะไร: ลดงานจัดหมวดและทำให้ค้นข้อมูลเก่าได้ง่ายขึ้น

## การทดลองเล็กที่สุด

1. สร้าง Issues ตัวอย่าง 10 เรื่อง
2. ให้ AI เสนอหมวดและแท็กโดยยังไม่แก้ไฟล์
3. ตรวจว่าข้อเสนอถูกต้องอย่างน้อย 8 จาก 10 เรื่องหรือไม่
4. ถ้าผ่าน จึงทดลองสร้างไฟล์ Markdown ผ่าน Pull Request

## สิ่งที่ยังไม่รู้

- ค่าใช้จ่ายเมื่อมีบันทึกจำนวนมาก
- วิธีป้องกันข้อมูลส่วนตัวถูกส่งออกไปโดยไม่ตั้งใจ
- AI จะเชื่อมโยงบันทึกเดิมได้แม่นเพียงใด
