# ตัวอย่างแหล่งข้อมูล — การเขียน Markdown บน GitHub

> ไฟล์นี้แสดงวิธีเก็บลิงก์พร้อมสรุปและเหตุผล ไม่เก็บเพียง URL เปล่า

## แหล่งข้อมูล

- ชื่อ: Basic writing and formatting syntax
- ผู้จัดทำ: GitHub Docs
- ลิงก์: https://docs.github.com/github/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax
- วันที่บันทึก: 2026-08-23

## สรุป

คู่มือพื้นฐานสำหรับเขียน GitHub Flavored Markdown ครอบคลุมหัวข้อ รายการ ลิงก์ รูปภาพ ตาราง รายการงาน การอ้างข้อความ และ Code Block

## เหตุผลที่บันทึก

ใช้เป็นคู่มืออ้างอิงเวลาต้องการจัดรูปแบบบันทึกให้อ่านง่าย โดยเฉพาะตาราง รายการงาน และลิงก์เชื่อมระหว่างไฟล์
