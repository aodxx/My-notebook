# 05 — Resources

พื้นที่เก็บข้อมูลอ้างอิงที่อยากกลับมาดู เช่น ลิงก์ เว็บไซต์ หนังสือ วิดีโอ เครื่องมือ และ Repository

ทุกแหล่งข้อมูลควรมี:

- ชื่อและลิงก์ต้นทาง
- วันที่บันทึก
- สรุปว่ามีประโยชน์อย่างไร
- คำค้นหรือแท็ก
- สิ่งที่จะนำไปใช้ต่อ (ถ้ามี)

อย่าเก็บเพียงลิงก์เปล่า เพราะภายหลังอาจจำไม่ได้ว่าเก็บไว้ทำไม
