# My Notebook

สมุดบันทึกส่วนตัวบน GitHub สำหรับเก็บเรื่องทั่วไป บันทึกประจำวัน ความรู้ ไอเดีย โปรเจกต์ และแหล่งข้อมูลที่ต้องการกลับมาใช้ภายหลัง

> **ก่อนเริ่มจดเรื่องส่วนตัว:** Repository นี้ยังเป็น Public อยู่ ควรเปลี่ยนเป็น **Private** ก่อนบันทึกข้อมูลส่วนตัว เอกสารสำคัญ หรือข้อมูลที่ไม่ต้องการเผยแพร่

## เริ่มใช้งาน

- มีเรื่องเข้ามาใหม่แต่ยังไม่รู้จะเก็บที่ไหน → จดไว้ใน [00-inbox](./00-inbox/)
- ต้องการบันทึกเรื่องที่เกิดขึ้นในแต่ละวัน → ใช้ [แม่แบบบันทึกประจำวัน](./templates/daily-note.md)
- ต้องการเก็บความรู้หรือเรื่องทั่วไป → ใช้ [แม่แบบบันทึกทั่วไป](./templates/general-note.md)
- มีไอเดียใหม่ → ใช้ [แม่แบบไอเดีย](./templates/idea.md)
- ใช้มือถือและต้องการจดให้เร็ว → เปิดแท็บ **Issues** แล้วเลือก **จดด่วน**

## หลักการตั้งชื่อไฟล์

ใช้รูปแบบนี้เพื่อให้เรียงตามเวลาและค้นหาได้ง่าย:

```text
YYYY-MM-DD-ชื่อเรื่องสั้นๆ.md
```

ตัวอย่าง:

```text
2026-08-23-ไอเดียจัดการงานสวน.md
2026-08-24-สิ่งที่เรียนรู้เรื่อง-apps-script.md
```

สำหรับบันทึกประจำวัน ให้เก็บตามเส้นทาง:

```text
01-daily/YYYY/MM/YYYY-MM-DD.md
```

## วิธีจดที่แนะนำ

1. จดทันทีใน `00-inbox` หรือผ่าน GitHub Issue แบบ **จดด่วน**
2. ใส่คำค้นสำคัญใน `tags` ของแม่แบบ
3. เมื่อมีเวลา ค่อยย้ายไปหมวดที่เหมาะสม
4. เดือนละครั้ง ตรวจ `00-inbox` และย้ายเรื่องที่จบแล้วไป `90-archive`

## วิธีค้นหา

- กด `/` บนหน้า Repository แล้วพิมพ์คำที่ต้องการค้นหา
- ค้นด้วยแท็ก เช่น `#สวนปาล์ม`, `#google-apps-script`
- ค้นด้วยชื่อไฟล์หรือวันที่ เช่น `2026-08`
- ใช้ Git history เพื่อย้อนดูว่าแก้ไขบันทึกอะไร เมื่อใด

## กติกาความปลอดภัย

อย่าบันทึกรหัสผ่าน, API key, access token, เลขบัตรประชาชน, ข้อมูลบัญชีธนาคาร หรือไฟล์ลับลงใน Repository แม้ตั้งเป็น Private แล้วก็ตาม
